What's in it

Everything on one engine

The GUI, the CLI, the MCP server and the load generator all execute requests through the same core, so what you see in the app is exactly what runs in CI.

GET

Five protocols, one workspace

REST, GraphQL, WebSocket, SSE and gRPC — gRPC via server reflection, so no .proto files or precompiled stubs. Same editor, same history, same environments across all of them.

POST

Load testing built in

Turn any saved request into a k6 load test without leaving the app. Live requests-per-second and p95 charts, SLA thresholds, and a plain pass/fail verdict.

MCP

An MCP server for your agent

AUK exposes itself over MCP, so Claude Code or any MCP client can list, run and load-test your saved requests directly. Anything mutating is gated behind an approval prompt.

JS

Pre- and post-request scripting

Real JavaScript hooks with test() and expect(). Chain an auth token out of one response and into the next request without copy-pasting a bearer token ever again.

CI

A CLI runner that gates builds

Run a folder headlessly, emit JUnit XML for your CI dashboard, and exit non-zero on failure. It's the same engine as the GUI, not a second implementation that drifts.

SPEC

Contract testing against OpenAPI

Validate live responses against your OpenAPI document and catch the moment the implementation and the spec disagree — undocumented fields, wrong types, missing required properties.

GIT

Git-native storage

Every workspace is plain YAML on disk. Diff it, review it in a pull request, sync it with whatever remote you already use. No cloud, no account, no lock-in.

KEY

Secrets in the macOS keychain

API keys and tokens live in the system keychain, not in the files you commit. Share a workspace with your team without leaking credentials into git history.

IMPORT

Bring your existing collections

Imports Postman, Insomnia, OpenAPI and raw cURL commands. Paste a cURL line and send it immediately — nothing to configure first.

Native macOS app built on a system webview — roughly 20 MB, no bundled Chromium. Every release is code-signed and notarized by Apple.

Nothing breaks. Your licence is perpetual: every version released during your 12-month window keeps working forever, on up to 3 Macs, with no further payment and no phone-home requirement. Is there a free trial?

Yes — 14 days, completely unlocked. Every feature is available during the trial, including k6 load testing, the MCP server and the CLI runner. No account, no credit card, no sign-up form: download the build, open it, and start sending requests.

A 14-day money-back guarantee, no questions asked. Email skumar5190@gmail.com within 14 days of purchase and the refund is issued to your original payment method by Paddle. The full terms are on the Refund Policy page.

Does AUK send my data anywhere?

No telemetry and no analytics. Your workspaces are plain YAML files on your own Mac, and secrets live in the macOS keychain. The app talks to a server for exactly two things: activating your licence, and checking GitHub for new releases. Git syncing is optional and points at whatever remote you configure. See the Privacy Policy.

How many machines can I use it on?

Three Macs on one licence — a laptop, a desktop and a spare, for example. You can deactivate a machine and move the seat to a new one at any time; email support if you lose access to an old Mac.

Which macOS versions are supported?

Recent macOS on both Apple Silicon and Intel. AUK is a native app built on the system webview rather than a bundled browser runtime, so the download is around 20 MB and every release is code-signed and notarized by Apple.
