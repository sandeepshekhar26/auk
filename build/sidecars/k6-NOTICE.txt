THIRD-PARTY NOTICE — k6
=======================

This application (AUK) ships a copy of k6 so that load testing works out of
the box. k6 is a separate program: AUK never links it, never embeds it into
its own binary, and never compiles it in via xk6. AUK only ever launches it
as an independent child process (`os/exec`) and talks to it over stdin/stdout
and files. AUK's own source code is therefore not a derivative work of k6.

  /Applications/AUK.app/Contents/Resources/bin/k6 version

REPLACING THE BUNDLED COPY
--------------------------

k6 is a plain, swappable file. To run a different build, either replace
Contents/Resources/bin/k6 in the app bundle, or set the environment variable
APITOOL_K6_BIN to the absolute path of the k6 binary you want AUK to use — it
takes precedence over the bundled copy.
